# MakeUp Ultra Fast - Native Metal Port

**Notice:** This is an unofficial, Native Apple Metal (MSL) port of the popular [MakeUp - Ultra Fast](https://modrinth.com/shader/makeup-ultra-fast) shaderpack by Javier Garduño.

This port was specifically rewritten from GLSL to MSL to run on **Prisma** (a Native Metal Shader Loader for macOS). It bypasses all OpenGL overhead, delivering maximum performance on Apple Silicon (M1/M2/M3).
